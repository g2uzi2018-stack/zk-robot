# TI5 T170C 灵巧手独立实机测试

## 用途

`ti5_hand_check` 只使用傲意灵巧手的 CAN 适配器，不初始化双臂、头部和腰部。
它直接复用工程中的 `Hand` 和 `HandController`，可分别测试左手、右手或双手，
也可以只移动六个原始通道中的一个。

工具支持两种检查：

- 只读检查：发现指定手的 CAN 接口并读取六通道位置及可用的力反馈，不发送
  位置命令。
- 运动检查：读取当前位置作为起点，小幅移出、端点确认、返回起点并确认。

## 硬件前提

先确认操作系统已经生成灵巧手适配器的 CAN 接口：

```bash
ip -brief link show type can
```

`hands.yaml` 当前按物理路径选择一个四通道 USB-CAN 适配器，所以这个适配器的
四个通道必须全部被系统识别。如果目前只看到本体的 `can0`～`can3`，工具会在
打开灵巧手协议之前停止；CAN 权限不能解决适配器没有生成接口的问题。

## 编译与权限

```bash
cd ~/workspace/zk_robot
cmake --build build --target ti5_hand_check -j"$(nproc)"

sudo setcap 'cap_net_admin,cap_net_raw=eip' \
  ./build/tools/ti5_hand_check
getcap ./build/tools/ti5_hand_check
```

每次重新链接 `ti5_hand_check` 后都要重新设置上述权限。程序会直接配置 CAN
接口，因此不要使用 `sudo ./build/tools/ti5_hand_check` 运行。

## 只读检查

只检查左手：

```bash
cd ~/workspace/zk_robot
ZK_ROBOT_CONFIRM_HAND_CHECK=YES \
./build/tools/ti5_hand_check --side left --read-only
```

只检查右手或同时检查双手时，将 `left` 改成 `right` 或 `both`。

## 小幅运动检查

当前 `hands.yaml` 仍将协议验证和控制开关保持为关闭状态。首次实机验证时必须显式
添加 `--commission`，并设置第二个确认变量。该选项只修改当前进程中的配置副本，
不会改写 `hands.yaml`。

只让左手六通道一起移动 20 个原始位置单位，然后返回：

```bash
cd ~/workspace/zk_robot
ZK_ROBOT_CONFIRM_HAND_CHECK=YES \
ZK_ROBOT_CONFIRM_UNVERIFIED_HAND_TEST=YES \
./build/tools/ti5_hand_check \
  --side left \
  --channel all \
  --delta-raw 20 \
  --speed-raw 5 \
  --commission
```

只让右手的原始通道 2 小幅运动：

```bash
ZK_ROBOT_CONFIRM_HAND_CHECK=YES \
ZK_ROBOT_CONFIRM_UNVERIFIED_HAND_TEST=YES \
./build/tools/ti5_hand_check \
  --side right \
  --channel 2 \
  --delta-raw 20 \
  --speed-raw 5 \
  --commission
```

允许范围：

| 参数 | 范围 |
|---|---|
| `--side` | `left`、`right`、`both`，必须明确指定 |
| `--channel` | `all` 或 `0`～`5`，默认 `all` |
| `--delta-raw` | 非零，绝对值不超过 50，默认 20 |
| `--speed-raw` | 1～20，默认 5 |

如果当前位置靠近原始数值边界，可以使用负位移，例如 `--delta-raw -20`。

## 操作和异常处理

1. 关闭其他机器人控制程序，清空手指周围的人体和物体。
2. 程序先发现接口、读取并打印当前位置，此时不会发送位置命令。
3. 确认接口映射和状态合理后，在终端输入 `y` 或 `Y` 才会开始运动。
4. 正常流程返回起始位置后停止继续发送命令。
5. 如果按 `Ctrl+C` 或发生通信异常，程序立即停止继续发送位置命令。

现有资料没有给出已经确认的灵巧手停止或释放命令。因此“停止继续发送”不能解释为
灵巧手已经断力、释放或进入安全模式；测试期间必须保证物理急停可以立即触达。

## 与整机测试的关系

这个工具是灵巧手部件的独立入口。它不需要双臂和头部处于位置控制模式，也不会
发送本体电机的模式切换命令。整机组合动作仍由 `build/robot` 执行。
