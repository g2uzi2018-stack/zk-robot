# TI5 T170C 头部 CAN 控制、编码器与坐标约定

本文是头部关节和 IMU 对接的独立接口说明，不依赖具体软件仓库。

## 1. 关节与节点

| 关节 | Node ID | 机械含义 |
|---|---:|---|
| neck_yaw | 30 | 头部绕竖直轴左右转动 |
| neck_pitch | 31 | 头部绕横向轴前后俯仰 |
| neck_roll | 32 | 头部绕前后轴左右侧倾 |

三个节点位于头部 CAN 总线。

## 2. CAN 命令

所有位置值均为 little-endian 有符号 `int32`，单位为输出端 encoder counts。

| 命令字 | 请求 DLC | 请求数据 | 响应 DLC 与数据 | 用途 |
|---|---:|---|---|---|
| `0x08` | 1 | `[08]` | `DLC=5 [08, position:int32_le]` | 读取当前位置 |
| `0x41` | 1 | `[41]` | `DLC=8 [I0..I1, V0..V1, P0..P3]` | 查询当前 CSP 反馈（电流 mA, 速度 0.01Hz, 位置 cnt） |
| `0x44` | 5 | `[44, target:int32_le]` | `DLC=8 [I0..I1, V0..V1, P0..P3]` | 发送位置 CSP 目标并获取反馈 |
| `0x03` | 1 | `[03]` | `DLC=5 [03, mode:int32_le]` | 读取运行模式（0: STOP, 8: PROFILE_POSITION 等） |
| `0x0A` | 1 | `[0A]` | `DLC=5 [0A, fault:uint32_le]` | 读取 32-bit 故障状态位图（0 表示无故障） |
| `0x02` | 1 | `[02]` | 无回显 | 电机去使能（若有抱闸则联动刹车） |

`0x44` 是头部位置控制主命令。发送目标前应确认驱动器故障值为 `0`，目标必须处于驱动器允许的位置范围（`0x1A/0x1B`）内。

位置控制过程中应周期性（如 50~100 Hz）发送 `0x44` 目标，并接收 8 字节 CSP 反馈。停止时可发送 `0x02` 执行去使能，或发送当前保持目标。

## 3. 编码器角度换算

输出端每圈为 `262144 counts`：

```text
angle_rad = raw_position * 2π / 262144
raw_position = trunc(angle_rad * 262144 / 2π)
angle_deg = angle_rad * 180 / π
```

位置角度直接按输出端计数换算，不再除以齿轮比。正负号由编码器计数本身决定。

## 4. 几何零位

当以下三个角度同时为 `0 rad`（`0°`）时，头部相对于机器人几何坐标系处于平直基准姿态：

```text
neck_yaw   = 0 rad
neck_pitch = 0 rad
neck_roll  = 0 rad
```

该姿态定义为：头部正面朝机器人前方，头部不向左或右旋转，头部不向前或后俯仰，头部不向左或右侧倾；三个几何维度均为水平/无倾斜状态。

## 5. 正方向

角度增加（`+`，等价于控制界面的 ↑）和角度减少（`-`，等价于 ↓）定义如下：

| 关节 | `+` 正方向 | `-` 负方向 |
|---|---|---|
| neck_yaw | 头部朝机器人左方转 | 头部朝机器人右方转 |
| neck_pitch | 头部朝机器人后方转 | 头部朝机器人前方转 |
| neck_roll | 头部朝机器人右方侧倾 | 头部朝机器人左方侧倾 |

左右、前后均以机器人自身坐标系为准。

## 6. IMU 对接

IMU 的零姿态应在三个关节均为 `0 rad` 的平直基准姿态下采集。将该时刻 IMU 的姿态记录为 IMU 零姿态，之后输出相对于该零姿态的姿态增量。

IMU 的安装坐标轴通常不等于机器人头部关节坐标轴，需要使用静态安装变换将 IMU 姿态转换到机器人坐标系。关节角来自三个节点的编码器位置反馈；IMU 姿态来自惯性测量和融合，两者应分别保留并通过时间戳对齐。
