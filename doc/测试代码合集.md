## 4. ti5_zero_home：回零与保持实机测试

完整操作、自然下垂采样表、恢复走廊和边界接管规则见原文：[TI5 T170C 一键回零测试](TI5_T170C_一键回零测试.md)。本节将其纳入统一记录，具体参数和操作流程以专项文档及当前代码为准。

### 4.1 测试范围

| 菜单 | 行为 |
| --- | --- |
| 1 | 头部和双臂共 17 轴回到 CAN 电机角 0 rad 并保持 |
| 2 | 双臂 14 轴经过两个中间点缓慢下放；托稳并再次确认后发送 STOP |
| 3 | 只读读取头部和双臂 17 轴当前位置，保存为 `config/ti5/t170c/recorded_waypoint.txt` 特定点 |
| 4 | 按已记录特定点做五次曲线运动，到达后建立 CSP HOLD |

排除腰部、折叠机构和左右灵巧手；菜单 2 不改变头部状态。回零目标为电机角 0，不等同于模型关节角 0，也不是重新设置编码器零点。

按现有专项文档，菜单 1 使用五次曲线同步回零，峰值速度不超过 0.15 rad/s，最终位置要求为目标 ±0.012 rad。菜单 2 使用本次起点至历史完整下垂参考的 1/3 和 2/3 中间点，峰值不超过 0.10 rad/s，不命令完整下垂点。

STOP 仅表示请求 mode=0，不能解释为已确认去使能、释放转矩或抱闸。菜单 1、4 完成后保留 HOLD，退出程序不会自动 STOP。菜单 3 只读并保存文件，不发送位置控制帧。完整前置检查和托臂要求见专项文档。

### 4.2 编译与操作入口

无动作检查：

```bash
cd /home/kuang/workspace/zk_robot
cmake --build build --target ti5_zero_home -j2
./build/tools/ti5_zero_home --dry-run
```

专项文档说明 --dry-run 不打开 CAN、不发帧。本次没有执行该检查或下列实机命令。

实机操作前阅读专项文档、关闭其他 CAN 控制程序，保证现场急停可达；涉及菜单 2 时按文档托稳双臂：

```bash
sudo env ZK_ROBOT_CONFIRM_TI5_TEST=YES ./build/tools/ti5_zero_home
```

程序仍需菜单选择和现场确认；菜单 3 的确认只针对读取和保存，不会发送位置控制帧。菜单 4 会运动机械臂，必须确认现场安全。CAN 已正确配置且有访问权限时，可按专项文档使用 --no-bring-up。

### 4.3 特定点文件与安全边界

菜单 3 保存电机输出端弧度值，文件包含 `TI5_WAYPOINT_V1 motor_rad` 版本头和 17 个关节名称。菜单 4 在发送控制帧前检查文件完整性、有限数值、`safety.yaml` 软件限位和驱动器 `0x1A/0x1B` 限位；不满足条件时拒绝运动。菜单 4 沿用 10 ms 控制周期、五次曲线和 0.15 rad/s 峰值速度，抵达后保持约 1 秒并复核位置。

本次已完成源码编译和 `--dry-run` 菜单检查；尚未在实机执行菜单 3/4，也未把当前姿态写入仓库。特定点文件属于机器人主机运行时数据，不应提交到版本库。
