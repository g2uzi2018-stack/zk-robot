# Qnbot Exoskeleton SDK 版本更新说明

更新时间：2026-06-04  
适用仓库：`qnbot-exoskeleton-SDK`

## 1. CLI 多语言机制新增

- `qnbot_cli.py` 新增语言参数：
  - `--lang auto`
  - `--lang zh-CN`
  - `--lang en-US`
- CLI 运行中新增语言切换命令：
  - `lang <auto|zh-CN|en-US>`

说明：

- `auto` 会根据系统环境自动选择语言。
- 当自动识别失败时，默认回退到 `zh-CN`。

## 2. 新增语言资源目录

- 新增目录：`qnbot_sdk_v1.2/locales/`
- 当前包含资源文件：
  - `zh-CN.json`
  - `en-US.json`

说明：

- CLI 输出文本通过语言资源进行映射替换，便于后续继续扩展更多语言。

## 3. 文档同步更新

- `qnbot_sdk_v1.2/SDK使用说明.md` 已同步新增语言能力说明：
  - 启动参数 `--lang auto|zh-CN|en-US`
  - 运行时命令 `lang <auto|zh-CN|en-US>`
  - `locales` 语言资源目录说明

## 4. 兼容性与影响范围

- 本次更新对既有核心协议调用逻辑保持兼容。
- CLI 与工具侧为增强型变更，默认行为可保持原使用习惯。
- 建议在 Windows 与 Linux 环境各执行一次基础连通测试（串口连接、命令执行、工厂流程）。

## 5. Haptics 向导与调试体验增强

- `haptics.*` 命令现已在 CLI `help` 中始终显示，便于不同机型现场快速确认可用能力。
- `haptics.wizard` 已增强为更完整的现场调试流程，包含：
  - 可用通道与手柄自动探测
  - `SetOutput + VibratePlay` 联合试播
  - 固定反馈强度测试
  - 扳机联动模拟
- `haptics.wizard` 的探测输出已裁剪，不再显示 `NOT_READY(0x03)` 项，仅保留有效结果。

说明：

- 当固件返回 `OK` 的通道/手柄存在时，向导会优先推荐这些组合。
- 若现场已知通道映射，仍可手动覆盖推荐值。

## 6. 固定反馈强度测试改造

- `haptics.wizard` 中原先偏向 `pressure=0..4095` 的阶梯试压流程，已调整为更直观的固定反馈强度测试：
  - 使用 `fixed_strength=0..100`
  - 内部映射为压力值后持续下发约 `3` 秒
- 该实现更接近上位机固定反馈测试的实际行为，避免体感上与前序短时试播时长混淆。

说明：

- 向导会打印：
  - 固定反馈强度 `fixed_strength`
  - 映射后的内部压力值
- 若测试过程中出现单次超时，会在现场摘要中记录超时次数，便于后续排查串口或固件响应抖动。

## 7. 扳机联动模拟并入向导

- 保留独立命令：
  - `haptics.trigger.sim <idx> [threshold] [poll_ms]`
- 同时将该能力并入 `haptics.wizard` 最后一步，便于现场一条流程走完。

说明：

- 当前扳机联动逻辑按业务规则使用有效区间 `512..3584`。
- 当 `threshold < 512` 时，实际起振起点仍按 `512` 处理。
- 运行中会显示：
  - 当前扳机值
  - 用户阈值
  - 实际起点
  - 当前映射压力值
